Using these files

Open index.html in a browser. The HTML files work offline and include navigation, responsive layouts and print styling. Use the Print / save as PDF button to export a readable copy. In the presentation, use the arrow keys or Page Up / Page Down to move through slides. Keep all four HTML files in the same folder when sharing.

Accuracy and release status

These documents describe the workspace as of 17 November 2026. PostgreSQL remains the supported production default. SQL Server and MySQL have local integration evidence and experimental installer labels. SMTP UI and security controls are implemented. The owner confirmed local MFA and password recovery. Production security review, trusted database TLS for all providers, upgrade and recovery rehearsals and release verification remain operational work. No revenue, conversion, uptime, certification or independent security-testing claims are made.
